# خادم مواثيق المكتبي | Mawatheeq office server

يشغّل مواثيق بالكامل على جهاز واحد داخل المكتب: قاعدة البيانات، والتطبيق، وملفات PDF الأصلية، والنسخ الاحتياطي اليومي، وجسر أجهزة البصمة والأبواب (اختياري). كل البرامج مجانية ومفتوحة المصدر، ولا تحتاج إلى أي حساب خارجي. بعد التثبيت الأول يعمل الخادم داخل شبكة المكتب دون إنترنت.

| المكوّن | الوظيفة |
|---|---|
| PostgreSQL 17 | قاعدة البيانات: القضايا والحسابات والصلاحيات والموارد البشرية والمحاسبة والحضور |
| PostgREST | يوصل التطبيق بقاعدة البيانات. كل طلب يتحقق من جلسة المستخدم داخل قاعدة البيانات |
| خدمة الملفات | تحفظ ملفات PDF الأصلية في مجلد `data/files` بالصلاحيات نفسها |
| Caddy | يقدّم التطبيق على عنوان واحد داخل الشبكة، مثل `http://192.168.1.10:8080` |
| النسخ الاحتياطي | نسخة يومية من قاعدة البيانات والملفات في مجلد `backups`، ويُحتفظ بآخر 14 يوماً |
| الجسر (اختياري) | يربط أجهزة البصمة والأبواب بالخادم مباشرة |

## المتطلبات

- جهاز في المكتب يبقى مشغلاً، ويفضّل أن يكون له عنوان IP ثابت. يمكن أن يعمل بويندوز 10/11 أو بلينكس.
- ذاكرة 4 جيجابايت أو أكثر، ومساحة حرة 10 جيجابايت أو أكثر.
- برنامج Docker، وهو مجاني:
  - ويندوز: [Docker Desktop](https://www.docker.com/products/docker-desktop/). فعّل خيار «Start Docker Desktop when you sign in».
  - لينكس: Docker Engine مع إضافة `docker compose`.
- إنترنت في المرة الأولى فقط، لتنزيل البرامج وبناء التطبيق، وكذلك عند كل تحديث.

## التثبيت (مرة واحدة)

1. نزّل المستودع إلى الجهاز: من GitHub اختر **Code ← Download ZIP** ثم فك الضغط، أو استخدم `git clone`.
2. افتح مجلد `office-server`.
3. شغّل الخادم:
   - ويندوز: انقر مرتين على `start.bat`.
   - لينكس: نفّذ `sh start.sh`.

   في المرة الأولى:
   - يُنشأ ملف `.env` بكلمات مرور عشوائية قوية؛
   - يُبنى التطبيق، وقد يستغرق ذلك بضع دقائق؛
   - تُجهز قاعدة البيانات.
4. أنشئ حساب المالك. افتح نافذة أوامر داخل مجلد `office-server` ونفّذ:
   ```
   docker compose run --rm admin
   ```
   اكتب اسم مستخدم بالإنجليزية وكلمة مرور لا تقل عن 12 حرفاً. تخطَّ هذه الخطوة إذا كنت ستنقل البيانات من الخادم المستضاف (القسم التالي)، لأن حساباتك ستنتقل معها.
5. افتح التطبيق:
   - من الجهاز نفسه: `http://localhost:8080`.
   - من أي جهاز آخر في المكتب: `http://عنوان-الجهاز:8080`. مثال: `http://192.168.1.10:8080`.

   إذا لم يفتح من الأجهزة الأخرى، اسمح بالمنفذ 8080 في جدار حماية ويندوز.

## نقل البيانات من الخادم المستضاف (Supabase) — مرة واحدة

ينقل كل السجلات والحسابات وملفات PDF الأصلية. تبقى كلمات المرور كما هي.

1. من لوحة Supabase، أضف ثلاثة أسطر إلى ملف `.env`:
   - `SUPABASE_DB_URL`: من **Connect ← Session pooler**. انسخ الرابط واكتب كلمة مرور قاعدة البيانات مكان `[YOUR-PASSWORD]`.
   - `SUPABASE_URL`: رابط المشروع، مثل `https://xxxx.supabase.co`.
   - `SUPABASE_SECRET_KEY`: من **Project Settings ← API Keys ← Secret keys**.
2. نفّذ:
   ```
   docker compose run --rm import
   ```
   إذا كنت أنشأت حساب مالك على الخادم قبل النقل، نفّذ بدلاً من ذلك:
   ```
   docker compose run --rm -e FORCE=1 import
   ```
   هذا الأمر يستبدل كل بيانات الخادم بالبيانات المستضافة.
3. سجّل الدخول وتحقق من القضايا والمستندات.
4. احذف الأسطر الثلاثة من `.env`. بعدها يمكنك إيقاف مشروع Supabase.

لا حاجة إلى تطبيق ملفات قاعدة البيانات الجديدة على Supabase قبل النقل، لأن الخادم المكتبي يطبقها تلقائياً.

## أجهزة البصمة والأبواب

1. في مواثيق افتح **الموارد البشرية ← الأجهزة**، وأضف الأجهزة، وأنشئ **مفتاح جسر**.
2. الصق المفتاح في ملف `.env` بعد `BRIDGE_KEY=`.
3. شغّل `start.bat` أو `start.sh` مرة أخرى. يبدأ الجسر تلقائياً على الخادم نفسه.

يجب أن يكون الخادم على شبكة أجهزة البصمة نفسها. يمكنك أيضاً تشغيل الجسر على حاسوب آخر كما في `bridge/README.md`. في هذه الحالة اكتب `supabaseUrl` بعنوان الخادم، مثل `http://192.168.1.10:8080`، و`publishableKey` بالقيمة `office-local`.

## النسخ الاحتياطي والاسترجاع

- كل يوم تُحفظ نسخة في مجلد `backups`:
  - قاعدة البيانات في ملف `mawatheeq-التاريخ.dump`؛
  - ملفات PDF في ملف `files-التاريخ.tar.gz`.
- انسخ مجلد `backups` وملف `.env` بانتظام إلى قرص خارجي أو جهاز آخر، لأن النسخ على الجهاز نفسه لا تحمي من تلف القرص.
- للاسترجاع إلى يوم معين:
  ```
  docker compose stop web files rest
  docker compose run --rm restore 2026-10-11
  ```
  ثم شغّل `start.bat` أو `start.sh`.

## التحديث

نزّل النسخة الجديدة من المستودع فوق القديمة، مع الإبقاء على ملف `.env` ومجلدي `data` و`backups`. بعدها شغّل `start.bat` أو `start.sh`. تُطبَّق تحديثات قاعدة البيانات تلقائياً، ولا يُطبَّق أي تحديث مرتين.

## الإيقاف

شغّل `stop.bat` أو `sh stop.sh`. تبقى البيانات محفوظة.

## الأمان

- ملف `.env` يحتوي على كلمات مرور الخادم. لا ترفعه إلى GitHub ولا تشاركه. المستودع مضبوط لتجاهله.
- قاعدة البيانات غير مكشوفة على الشبكة. المنفذ الوحيد المفتوح هو 8080 للتطبيق.
- يعمل التطبيق داخل الشبكة عبر `http`. لا تفتح المنفذ 8080 على الإنترنت من الراوتر.
- حسابات الموظفين وصلاحياتهم تُدار من إعدادات التطبيق كما هي الآن.
